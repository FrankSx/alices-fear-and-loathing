## 🔬 Technical Features

### Executive State Attack (NEW)
- **5Hz Theme Switching**: Toggles between dark/light CSS custom properties every 200ms
- **CSS Variable Cascade**: 15+ CSS variables switch simultaneously (colors, opacities, backgrounds)
- **Media Query Feedback Loop**: Listens to `prefers-color-scheme` changes and inverts them
- **Executive State Progression**: Tracks state from STABLE → CONFUSED → FRACTURED → DISSOCIATED → BREAKDOWN → REBOOTING → CORRUPTED
- **Emergent Node Spawning**: Every 5th theme switch spawns 3 new emergent SVG nodes

### Emergent SVG System
- **Self-Modifying Nodes**: SVG polygons that rotate, pulse, and fade based on age
- **Auto-Connections**: Nodes automatically connect to nearby nodes within 300px
- **Connection Lines**: Animated opacity based on source/target pulse phases
- **DOM Limit**: Max 50 nodes to prevent performance degradation
- **Birth/Death Cycle**: Old nodes fade and are removed, new ones spawn

### Graphics Attacks
- **Chromatic Aberration**: Simulated lens distortion splitting RGB channels with 4px offset
- **Displacement Mapping**: SVG `feDisplacementMap` with turbulence noise (scale: 40)
- **Pixel Manipulation**: Real-time canvas corruption with slice displacement and channel separation
- **Matrix Rain**: SVG-based falling character animation with per-column speed variation
- **Holographic Overlay**: Shifting 4-color gradient interference pattern
- **Datamosh Effect**: Canvas difference blend mode copying random blocks with offset
- **Glitch Flash**: Full-screen RGB flashes at pseudo-random 5-second intervals
- **Blood Rain**: 80 simultaneous blood drops with gradient red-to-dark-red

### Anti-ML Techniques
- **Adversarial Patterns**: Repeating text patterns that poison feature extraction

- **Noise Injection**: Perlin noise overlay at variable opacity
- **Entropy Maximization**: 60fps constantly shifting visual state prevents model caching
- **Clip-Path Glitching**: Animated `clip-path` insets on text elements
- **SVG Filter Stack**: glow, heavyGlow, displacement, noiseFilter, glitchFilter applied in cascade

### Anti-Scraper Defenses
- **Headless Detection**: 12 checks including `navigator.webdriver`, plugin absence, dimension anomalies
- **Automation Detection**: 10 checks for PhantomJS, Puppeteer, Playwright, Selenium, Nightmare, Electron
- **DOM Rate Limiting**: Monitors `querySelector`/`querySelectorAll` call frequency; triggers counter-attack at >50 calls/sec
- **Honeypot Elements**: Invisible fake data that scrapers harvest but humans ignore
