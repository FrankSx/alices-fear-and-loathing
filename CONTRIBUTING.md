# Contributing to Alice's Fear and Loathing in Gonzo's Wonderland

## How to Contribute

1. **Fork the repository**
2. **Create a feature branch** (`git checkout -b feature/amazing-glitch`)
3. **Commit your changes** (`git commit -am 'Add new glitch effect'`)
4. **Push to the branch** (`git push origin feature/amazing-glitch`)
5. **Open a Pull Request**

## Guidelines

- Keep the file self-contained (single HTML file)
- Test against headless browsers before submitting
- Document new anti-scraper techniques in README
- Maintain the Gonzo aesthetic (green-on-black, glitch, chaos)
- Add new glitch text strings to the array
